# 编译说明（Build Guide）

本文档说明如何在 Windows 上从零编译本项目，生成 Release x64 可执行文件与安装程序 `Setup.exe`。

---

## 一、环境准备

### 1. 必需

| 组件 | 版本 | 说明 |
| --- | --- | --- |
| Windows | 10 1809+ / 11 x64 | 项目目标框架为 `net8.0-windows` |
| .NET SDK | **8.0.100 或更高** | 下载：<https://dotnet.microsoft.com/download/dotnet/8.0>（选择 SDK x64） |

验证：

```powershell
dotnet --list-sdks
# 应输出形如：8.0.4xx [C:\Program Files\dotnet\sdk]
```

### 2. 推荐（二选一即可）

* **Visual Studio 2022 17.8+**：安装时勾选工作负载 **「.NET 桌面开发」**（会自动带上 .NET 8 SDK 与 WPF 支持）。
* 或 **VS Code + C# 扩展**，配合命令行编译。

### 3. 可选

* **Inno Setup 6**：仅当你希望用 `.iss` 脚本生成安装包时需要（项目自带安装程序项目，默认不需要）。
* 网络：首次还原需要访问 `nuget.org` 下载 `Microsoft.Web.WebView2` 包。

---

## 二、编译方式 A：Visual Studio（图形界面）

1. 双击打开解决方案 **`L4D2ModManager.sln`**。
2. 确认顶部工具栏：**解决方案配置 = Release**，**解决方案平台 = x64**。
   * 若平台下拉框中没有 `x64`，见文末「四、常见问题」。
3. 在「解决方案资源管理器」中右键 **`L4D2ModManager.App`** → **设为启动项目**。
4. 菜单 **生成 → 生成解决方案**（或 `Ctrl+Shift+B`）。
5. 生成结果：
   * 主程序：`src\L4D2ModManager.App\bin\x64\Release\net8.0-windows\L4D2ModManager.exe`
   * 直接 `F5` 即可调试运行（`Ctrl+F5` 不调试运行）。
6. 若要单文件发布：右键 `L4D2ModManager.App` → **发布** → 目标 `文件夹` → 部署模式 `独立` →
   目标运行时 `win-x64` → 发布。

> 生成 `Setup.exe` 需要先把主程序发布目录压缩成 `src\L4D2ModManager.Setup\payload.zip`，
> 这一步由脚本自动完成，建议直接使用下面的命令行方式生成安装包。

---

## 三、编译方式 B：命令行（推荐，可一键产出全部产物）

在项目根目录（含 `L4D2ModManager.sln` 的目录）打开 PowerShell：

```powershell
# 1) 日常编译（Release）
pwsh -File .\build\build.ps1

# 2) 运行自检程序（16 项：VPK 解析 / 启停 / 分类 / 冲突 / 方案 / 安装删除 / 链接解析 …）
pwsh -File .\build\test.ps1

# 2b) 用本机真实的 L4D2 addons 目录做进一步验证（可选，推荐）
pwsh -File .\build\test.ps1 -AutoDetectSteamDirectory

# 3) 一键发布：主程序 exe + 便携包 + 单文件安装程序
pwsh -File .\build\build-release.ps1
```

`build-release.ps1` 的产物（位于 `artifacts\`）：

| 产物 | 说明 |
| --- | --- |
| `Setup.exe` | 单文件安装程序（自包含，双击即可安装，支持静默安装与卸载） |
| `L4D2ModManager-win-x64\L4D2ModManager.exe` | 便携版主程序，可直接运行 |
| `L4D2ModManager-win-x64-portable.zip` | 便携版压缩包 |

### 脚本参数

```powershell
# 跳过自检（更快）
pwsh -File .\build\build-release.ps1 -SkipTests

# 生成依赖 .NET 8 桌面运行时的轻量版本（体积更小，约 3 MB）
pwsh -File .\build\build-release.ps1 -FrameworkDependent

# 发布时用真实 Mod 目录做端到端验证
pwsh -File .\build\build-release.ps1 -RealVpkDirectory "D:\SteamLibrary\steamapps\common\Left 4 Dead 2\left4dead2\addons"
```

### 等价的原始 dotnet 命令

```powershell
# 还原（使用仓库内 NuGet.config，避免继承机器上的私有源）
dotnet restore src\L4D2ModManager.Core\L4D2ModManager.Core.csproj --configfile NuGet.config
dotnet restore src\L4D2ModManager.App\L4D2ModManager.App.csproj   --configfile NuGet.config
dotnet restore tests\L4D2ModManager.Tests\L4D2ModManager.Tests.csproj --configfile NuGet.config
dotnet restore src\L4D2ModManager.Setup\L4D2ModManager.Setup.csproj   --configfile NuGet.config

# 编译
dotnet build L4D2ModManager.sln -c Release --no-restore

# 发布主程序（自包含、win-x64）
dotnet publish src\L4D2ModManager.App -c Release -r win-x64 --self-contained true -o artifacts\app

# 生成安装载荷 + 安装程序
Compress-Archive -Path artifacts\app\* -DestinationPath src\L4D2ModManager.Setup\payload.zip -Force
dotnet publish src\L4D2ModManager.Setup -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o artifacts\setup
```

## 四、常见问题

**1. 解决方案平台里没有 `x64`？**
`L4D2ModManager.sln` 已包含 `x64` 配置。若你的 VS 没显示，可在 **生成 → 配置管理器** 中
「活动解决方案平台 → 新建 → x64 → 从 Any CPU 复制」。所有项目的 `PlatformTarget` 都已经固定为 `x64`，
即使选 `Any CPU` 也会生成 64 位程序。

**2. `dotnet restore` 报错找不到包 / 连不上 nuget.org？**
检查网络与代理；也可以先在浏览器打开 <https://api.nuget.org/v3/index.json> 确认可访问。
国内网络建议配置镜像源，或直接在 `NuGet.config` 中添加可用的包源。

**3. `dotnet` 命令找不到（只装了运行时）？**
说明装的是 Runtime 而不是 SDK，请安装 **.NET 8 SDK**。用 `dotnet --list-sdks` 区分：
只有 `--list-runtimes` 有输出，就说明缺 SDK。

**4. 编译提示 `NETSDK1045 当前 .NET SDK 不支持 net8.0`？**
SDK 版本过低，请安装 8.0.100 以上版本；或安装 VS 2022 17.8+。

**5. 运行主程序时提示缺少 WebView2？**
安装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)（Win11 与新版 Win10 已内置）。
缺失只影响「创意工坊」页面，其他功能正常。可用 `L4D2ModManager.exe --diagnose` 查看检测结果。

**6. 没有管理员权限能编译/安装吗？**
可以。编译不需要管理员权限；安装程序默认检测权限，无管理员权限时安装到
`%LocalAppData%\Programs\L4D2 Mod Manager`。

**7. 只想快速试一下，不想装 SDK？**
使用别人已生成的 `artifacts\Setup.exe`（自包含，不需要 .NET 运行时）。

## 五、项目编译属性说明（便于二次开发）

* `Directory.Build.props`：统一 `LangVersion`、可空引用类型、版本号、`EnableWindowsTargeting`。
* `L4D2ModManager.Core`：`net8.0-windows`（使用注册表 API 探测 Steam，不依赖 WPF，可单独测试）。
* `L4D2ModManager.App`：`net8.0-windows` + `UseWPF` + `PlatformTarget=x64` + `Microsoft.Web.WebView2`。
* `L4D2ModManager.Setup`：`WinExe` + `PublishSingleFile` + `SelfContained`，把 `payload.zip` 作为嵌入资源。
* `tests\L4D2ModManager.Tests`：纯控制台自检程序，**不依赖任何测试框架**，因此离线也能跑
  （`dotnet run` 或直接执行生成的 exe）。

运行自检时会自动把数据目录重定向到程序目录下的 `TestSandbox`，
绝不会读写你真实的 `%AppData%\L4D2ModManager`，也不会修改真实的 Mod 文件。
