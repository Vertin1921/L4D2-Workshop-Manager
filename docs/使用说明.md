# 使用说明（User Guide）

## 一、首次启动

1. 双击 `L4D2ModManager.exe`（或从开始菜单启动安装后的版本）。
2. 程序自动探测 Steam 安装位置（注册表 `HKCU\Software\Valve\Steam\SteamPath` +
   `steamapps\libraryfolders.vdf`），把下列目录加入扫描列表：
   * `…\steamapps\common\Left 4 Dead 2\left4dead2\addons`
   * `…\steamapps\workshop\content\550`
3. 自动开始扫描，状态栏显示进度；扫描完成后列表按「禁用优先 + 名称」排序。

> 如果没检测到 Steam：进入 **设置 → Mod 目录 → 添加目录**，手动选择你的 `addons` 文件夹
> （例如 `D:\Games\L4D2\addons`、`E:\L4D2 Mods`、`F:\SteamWorkshopBackup`）。

| 排序下拉 | 默认（禁用优先）、名称 A-Z、名称 Z-A、最近添加、最早添加、文件大小 ↑↓、按分类 |
| 分类下拉 | 全部 / 🔫武器 / 👤人物 / 🎵音频 / 🗺地图 / ⚙脚本 / 🎨UI / ❓其他 |
| 状态下拉 | 全部 / 已启用 / 已禁用 |
| 只看冲突 | 只显示与其他 Mod 有重复文件的 Mod |
| 批量按钮 | 启用全部、禁用全部、启用/禁用当前列表（受筛选影响）、启用/禁用所选（勾选项） |
| ➕ 添加 Mod | 粘贴创意工坊链接或 ID，自动获取信息并加入下载队列 |

**右键菜单**：启用/禁用、打开目录、复制文件路径、复制创意工坊链接、查看详情、删除。

**拖放安装**：把一个或多个 `.vpk` 文件（或包含 vpk 的文件夹）拖到窗口任意位置，
松开后会自动复制到下载目录、解析信息并加入列表。

## 三、启用 / 禁用（重要）

* 启用 = 文件名 `xxx.vpk`
* 禁用 = 文件名 `xxx.vpk.disabled`
* 游戏只加载 `addons` 目录下 `.vpk` 结尾的文件，因此改后缀即可启停。
* 程序**只重命名文件**，绝不修改 VPK 内容，也不会删除文件（删除是单独的显式操作并需要确认）。

## 四、创意工坊页面

* 页面完全在程序内部（WebView2）显示，**不会打开外部浏览器**。
* 顶部工具栏：`⬇ 下载 Mod`、`⬇ 下载合集`（左上角固定）、前进/后退/刷新/主页、地址栏、搜索框、热门/最新/最高评分。
* **打开某个 Mod 页面就会自动获取信息**（标题、作者、大小、标签、预览图），右侧面板自动填好；
  此时点 `⬇ 下载 Mod` 直接加入下载队列 —— **不需要先点「获取信息」**。
* 右侧面板也可以直接粘贴工坊链接或 ID，然后点「下载此 Mod」。
* **下载合集**：在合集页（Steam 的 Collection）点一下即可抓取页面上所有工坊物品并批量入队
  （程序直接读取页面里的物品链接，不依赖额外接口；一次最多 200 个，接口按 100 个一批查询）。
* 点击页面上的「订阅」等 `steam://` 链接时，程序会拦截该链接并自动解析为工坊 ID（不会启动外部程序）。

### 下载失败怎么办？（三种通道自动降级）

程序按顺序尝试：

1. **HTTP 直链（Steam UGC）** —— 最快，支持断点续传、暂停；
2. **Steam 订阅缓存** —— 你在 Steam 里订阅过该 Mod 时，直接从 `steamapps\workshop\content\550\<id>` 复制；
3. **steamcmd** —— 本机装了 `steamcmd.exe` 时调用 `workshop_download_item`。

**重点**：如果 `api.steampowered.com` 访问不了（国内很常见），程序**不会**因此拒绝下载 ——
它会直接按工坊 ID 入队，只用第 2、3 条通道；右侧状态栏与下载页会写明原因。
这种情况下最稳的做法是：在 Steam 里点一次「订阅」，再回到「下载管理」点「重试」，程序会自动复制文件。

## 五、下载管理

每个任务显示：标题、状态、进度条、已下载/总大小、实时速度、当前下载通道、错误信息。

| 按钮 | 说明 |
| --- | --- |
| 暂停 / 继续 | 基于 `ManualResetEventSlim`，支持 HTTP 通道暂停；继续时自动断点续传 |
| 取消 / 重试 | 取消后可重试；HTTP 通道保留 `.part` 文件，重试时用 `Range` 续传 |
| 📂 打开文件位置 | 定位到下载完成的 `.vpk` |
| 🔗 复制链接 | 复制工坊链接 |
| 🧹 清除已完成 | 清理列表中的完成项 |

**下载通道（自动依次尝试）**

1. **HTTP 直链（Steam UGC）** — 最快，支持断点续传、暂停、限速统计。
2. **Steam 订阅缓存** — 你在 Steam 中已订阅过该 Mod 时，直接从
   `steamapps\workshop\content\550\<id>` 复制，最可靠。
3. **steamcmd** — 若本机有 `steamcmd.exe`（可在设置中指定路径），执行
   `+login anonymous +workshop_download_item 550 <id> +quit` 后复制结果。

三条通道都失败时，最稳妥的办法：在 Steam 中订阅该 Mod → 回到下载页面点「重试」。
（L4D2 的工坊内容对匿名接口并不总是开放，这是 Steam 侧的限制。）

下载完成后程序会自动重新扫描并把新 Mod 加入列表。

## 六、冲突检测

程序解析每个 VPK 的内部文件清单（含每个文件的 **CRC32**），据此做**精确**判定，而不是"同名就算冲突"：

| 判定规则 | 结果 |
| --- | --- |
| 多个 Mod 包含同一路径，但 **CRC32 完全一致**（内容一模一样，只是重复打包） | **不算冲突**，标记为「内容相同」，默认隐藏 |
| 多个 Mod 包含同一路径且内容不同，位于 `models/ materials/ sound/ maps/ particles/` | **高严重程度**：资源覆盖，必须取舍 |
| 同上但位于 `scripts/ resource/ missions/` | **中严重程度**：脚本 / 定义覆盖 |
| 其他位置 | 低严重程度 |
| `addoninfo.txt`、`addonimage.*`、`readme.txt`、`sound.cache` 等描述/缓存文件 | 自动忽略 |
| 常见共享脚本库（`scripts/vscripts/director_base_addon.nut`、`_lib`、`shared`、`wabisuke` 等） | 自动忽略（可在设置里追加自己的规则） |

界面能力：

* 顶部筛选：**只看资源覆盖**（影响最大）、**只看同时启用**（真正会互相覆盖）、**显示内容相同项**（默认关）；
* 每条冲突显示**类型徽章**（资源覆盖 / 脚本·定义 / 其他 / 内容相同）与颜色（红 / 橙 / 灰）；
* 每个参与 Mod 旁有「禁用 / 启用」按钮，「保留此项」会禁用同一冲突中的其他 Mod；
* 摘要行会写明「N 个真实冲突文件（其中 M 个资源覆盖）… 另有 K 个文件内容完全相同（已判为无影响）」。

> 实测：本机 107 个真实 Mod 共 39,690 个内部文件，改进前会报 2,361 个"冲突"，
> 改进后只剩 **359 个真实冲突**（2,301 个内容相同的重复被正确排除）。

如果某个文件在你的环境里"人人都带"但内容不同（例如自定义公共库），
可在「设置 → 冲突检测 → 自定义忽略关键字」里按**内部路径子串**排除（每行一个）。

## 七、配置方案

| 内置方案 | 规则 |
| --- | --- |
| 单人模式 | 全部启用 |
| 联机模式 | 关闭 ⚙脚本 类 Mod、关闭互相冲突的 Mod，保留模型/材质/音频 |
| 写实模式 | 关闭 🔫武器 与 ⚙脚本 类（保留原版枪械手感），关闭冲突项 |
| 枪械模式 | 只启用 🔫武器 与 🎨UI 类 |

内置方案基于**分类 + 冲突检测结果动态计算**，新加入的 Mod 会自动纳入规则，因此不需要反复维护。

保存自定义方案：在右侧填写名称（可选备注）→「💾 保存为新方案」，记录当前所有 Mod 的启停状态；
之后随时「应用」。内置方案不可删除，自定义方案可删除。

## 八、设置页面

* **数据位置**：一键打开数据目录 / 日志 / 配置文件 / 数据库 / 缩略图目录，清空缩略图缓存。

## 十、排错

| 现象 | 处理 |
| --- | --- |
| 工坊页面空白 | 安装 WebView2 Runtime；用 `L4D2ModManager.exe --diagnose` 确认 |
| 扫描不到 Mod | 设置里确认目录正确；`addons` 目录下应有 `.vpk`；点「🔄 重新扫描」 |
| 显示的名字是数字 ID | 该文件没有 `addoninfo.txt`，程序按工坊 ID 命名；点开详情可用工坊链接查看 |

| 冲突太多 | 用「联机模式」方案，或在冲突页面用「保留此项」逐个处理 |
| 程序异常 | 把 `%AppData%\L4D2ModManager\logs` 下最新日志发给开发者 |

## 十一、安装与卸载

**安装（推荐形态）**：解压 `Setup.zip`，运行其中的 `L4D2ModManager.Setup.exe`（与 `payload.zip` 必须放在同一目录）。
安装程序是普通 .NET 程序，清单声明了管理员权限，所以双击会直接弹一次 UAC，确认后默认装到 `Program Files`。

```powershell
L4D2ModManager.Setup.exe                      # 图形向导
L4D2ModManager.Setup.exe /S /dir=D:\L4D2MM    # 静默安装
L4D2ModManager.Setup.exe /uninstall           # 卸载（图形）
```

不想安装也可以用便携版：解压 `L4D2ModManager-win-x64-portable.zip`，直接运行里面的 `L4D2ModManager.exe`。

**覆盖更新（升级到新版本）**

装过之后**再次运行 `Setup.exe` 就行**，安装程序会自动：

1. **识别已安装目录** —— 从卸载注册表项里读出上次的安装位置，直接填入路径框，标题变成「更新 Left 4 Dead 2 Mod Manager」，按钮变成「更新」，不需要你再选一次目录；
2. **自动关闭正在运行的程序** —— 先发关闭消息让它正常保存配置，超时后才强制结束；关不掉（例如它以管理员身份运行）会明确提示你手动退出，而不是装到一半报文件占用；
3. 覆盖安装完成后按勾选项重新启动程序。你的 **Mod 文件、配置、数据库、缩略图都不会动**（它们在 `%AppData%\L4D2ModManager`）。

命令行同样支持覆盖更新：`Setup.exe /S`（不带 `/dir` 时会自动用已安装目录）。

**卸载方式**

* 控制面板 / 设置 →「应用和功能」→ Left 4 Dead 2 Mod Manager；
* 开始菜单 →「L4D2 Mod Manager → 卸载 L4D2 Mod Manager」；
* 命令行：`L4D2ModManager.exe --uninstall`（`--silent` 静默，`--removedata` 同时删除用户数据）。

卸载会删除程序文件与快捷方式；**你的 Mod 文件（.vpk）永远不会被删除**，
是否删除配置/数据库/缩略图缓存由你在卸载时选择。便携版直接删除文件夹即可。

> 说明：卸载时正在运行的程序自身与已映射的 .NET 运行时 DLL 无法立即删除，
> 程序会把它们登记为「**下次重启后自动清理**」，并在结果里告诉你数量（例如"已删除 222 个文件，
> 另有 47 个文件正被占用，将在下次重启后自动清理"）。这是 Windows 的正常行为，
> 重启一次后安装目录就会彻底消失；不需要手动处理。

## 十二、管理员权限与拖放安装

**启动时自动请求管理员权限**：双击运行会弹一次 UAC，确认后即以管理员身份运行
（作用等同于在程序清单里写 `requireAdministrator`，但可以用下面的方式关闭）。

* 关闭方式一：「设置 → 性能与权限 → 启动时自动请求管理员权限（UAC）」取消勾选；
* 关闭方式二：命令行加 `--no-elevate`；
* 也可以右键程序 → **以管理员身份运行**；
* 已经以普通权限运行时，界面顶部会出现提示条，点「以管理员身份重启」即可提权重启，点「不再提示」则不再出现。

**为什么需要管理员权限？** 如果 Steam 装在 `C:\Program Files (x86)`，启用/禁用 Mod（重命名 `.vpk`）、
下载到 addons 目录都属于写受保护目录，普通权限会失败。此时程序会给出明确错误提示。

**拖放安装的注意事项（重要）**：Windows 出于安全考虑（UIPI）**禁止管理员程序接收来自资源管理器的拖放**。
所以以管理员身份运行时：

* 拖放不会有反应 —— 这是系统行为，不是程序缺陷；
* 请改用「Mod 管理」页面右上角的 **📂 添加 Mod 文件** 按钮，可一次选择多个 `.vpk`，
  行为和拖放完全一致（复制到下载目录 → 解析 addoninfo → 加入列表）；
* 如果更习惯拖放，可在设置里关闭启动提权、重启后再拖放（但可能无法写入受保护目录）。

| Launchpad 式页面切换 | 切换左侧导航时：淡入 + 上移 + 0.985→1 的轻微缩放 |

| 卡片悬停抬升 | 鼠标悬停时卡片上浮 2px，分类色条点亮 |
| 按钮弹簧反馈 | 悬停放大（BackEase 轻微过冲）、按下回弹 |

### SmartScreen「Windows 已保护你的电脑」

现象：双击 `Setup.exe` 或主程序时弹出蓝色窗口，显示 **发行者：发布者未知**，只有「不运行 / 仍要运行」。
**这不是报毒**，而是 Windows 对"从网络下载 + 未数字签名"的程序的标准拦截（Mark of the Web）。

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 解除下载标记（最快） | `pwsh -File .\tools\Unblock-Files.ps1`，或右键文件 → 属性 → 勾选「解除锁定」 | 本机立即可用；**压缩包要先解锁再解压** |
| 直接放行 | 弹窗里点「更多信息」→「仍要运行」 | 临时放行 |
| 代码签名（推荐） | `tools\New-DevCertificate.ps1` 生成本机开发证书 → `tools\Sign-Artifacts.ps1` 签名；构建时可用 `-Sign` | 本机彻底不再提示；分发给别人需要正式 OV/EV 证书 |

> 自签名证书只在你签署并信任它的机器上有效。要让所有用户都看到你的名字且不再被拦截，
> 必须使用受信任 CA 签发的代码签名证书，再用
> `tools\Sign-Artifacts.ps1 -PfxPath your.pfx -PfxPassword ***` 签名。
>
> 校验签名是否"生效"：`Get-AuthenticodeSignature 文件` →
> **Valid** 表示证书已被信任（SmartScreen 不再提示）；
> **UnknownError** 表示签名已写入但证书未被信任（自签名 + 未导入信任区时就是这个状态）。

### 杀软误报

本程序是自编译、未签名的 .NET 应用，且会重命名 Steam 目录中的文件，容易被启发式引擎误判。已经做的降低措施：

* 安装包**不再是单文件自解压**：改为小体积的 `Setup.exe` + 同目录 `payload.zip`（普通 .NET 程序读取外置 zip）；
* **不再把 62MB 载荷内嵌进 exe**（内嵌大体积二进制资源是高风险特征）；
* 卸载**不再生成 .cmd / .bat 脚本**，也不再调用 `cmd /c rmdir /s /q`（改为纯 .NET 重试删除，占用文件登记为重启后清理）；
* 安装程序在**清单里声明 `requireAdministrator`**（安装器的正常形态），不再用运行时 `runas` 自提升；
* 所有可执行文件都写入了完整的公司 / 产品 / 文件说明 / 版权 / 版本信息。

仍然被拦时（各厂商规则差异很大）：

1. **加白名单**（仓库自带脚本，需管理员）：
   `pwsh -File .\tools\Add-DefenderExclusion.ps1`
   若文件已被隔离，先到「Windows 安全中心 → 病毒和威胁防护 → 保护历史记录」恢复；
2. **提交误报**：<https://www.microsoft.com/en-us/wdsi/filesubmission>（选 Software developer，附源码地址），通常 1–3 天解除；
3. **代码签名**（最有效，能同时消除 SmartScreen 警告）：
   `signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 artifacts\Setup\L4D2ModManager.Setup.exe`；
4. 或改用 Inno Setup 生成安装包（`installer\L4D2ModManager.iss`）后再签名。

> 如果你更看重"单个文件分发"，可以用 `build-release.ps1 -SingleFileInstaller` 生成自解压单文件安装包，
> 但它的误报概率明显更高，因此默认不是这个形态。

## 十四、键盘与交互小技巧

* 标题栏双击 = 最大化/还原；支持拖拽标题栏移动窗口、边缘拖拽调整大小。
